# TJ-Task-2026-Anshika
Responsive Flipkart clone website

Live Demo: https://thenooblearner.github.io/TJ-Task-2026-AnshikaSingh/

Approach: The goal was to recreate the core layout and visual style of an e-commerce homepage (inspired by Flipkart), with a focus on responsiveness and clean structure.

Layout: Built the page section by section — a sticky navbar, a category strip, a promotional banner, an about section, a featured products grid, customer testimonials, and a contact form — each as its own semantic HTML section.

Styling: Used Flexbox for the navbar and category alignment, and CSS Grid for the product and testimonial cards, so both layouts automatically adjust to the number of items and screen size.

Responsiveness: Added a media query for smaller screens so the navbar stacks vertically, nav links wrap, and the category strip becomes horizontally scrollable instead of squeezing everything together.

Design choices: Kept the color palette close to Flipkart's (blue navbar, yellow accents) while giving cards consistent padding, rounded corners, and subtle shadows for a modern look.

Interactivity: The navbar links use anchor tags (#home, #about, #products, etc.) to jump to their respective sections on the same page.

Features:
-> Sticky navigation bar with "search" and "login" button
-> Category browsing section
-> Promotional banner
-> About section
-> Featured products grid (responsive card layout)
-> Customer testimonials section
-> Contact form with basic input validation (required fields)
-> Fully responsive design for mobile and tablet screens

Tech Stack:
1. HTML5
2. CSS3 (Flexbox, Grid, Media Queries)
